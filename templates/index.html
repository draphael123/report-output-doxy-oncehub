Help & Tutorial

Getting Started

Upload your data files to generate comprehensive weekly reports. All required files must be uploaded before generating a report.

Required Files:

  • Doxy Report (CSV/Excel)
  • Account Detail Report (CSV/Excel)
  • Gusto Hours (CSV/Excel)

Optional: OnceHub Booking Summary

Keyboard Shortcuts

Generate Report Ctrl + Enter
Preview Data Ctrl + P
Command Palette Ctrl + K
Toggle Theme Ctrl + T
Copy to Clipboard Ctrl + C
Print View Ctrl + P

Features

Preview: Review your data before generating the full report. You can sort, filter, and search through the preview.

Charts: Visualize your data with interactive charts in the preview modal.

Export: Generate Excel reports, export to PDF, or download individual sheets as CSV.

Dark Mode: Toggle between light and dark themes using the button in the header.

Tips

  • Drag and drop files directly onto the upload areas
  • Use the preview feature to catch errors before generating
  • Check file sizes - maximum 10MB per file
  • Ensure date ranges match across all files
